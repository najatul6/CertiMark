# 📖 About

CertiMark is a modern MERN stack application developed to simplify certificate issuing, management, and verification. The platform enables users to securely manage digital certificates while providing a responsive, user-friendly, and reliable experience across all devices.

- 🎓 Digital Certificate Management

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/najatul6/CertiMark.git
```

Move into the project

```bash
cd CertiMark
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
